# Other properties (R3) — owner: Bhajneek

Importers for the org's other sites (e.g. SikhiWiki) go here. Each one should
output records in the qa.jsonl schema with `"source_type": "secondary"` and a
clear `source` name, then be merged with the primary dataset. The org's own Q&A
dataset stays `"source_type": "primary"` and is weighted first.
